# Live Text Scanner

A phone web app: point the camera at a note, press **Scan**, and it reads the text from the live camera feed (no photo needed), skipping lines it already has. Press **Done** to save everything as a `.docx`.

Runs entirely in the browser with [Tesseract.js](https://github.com/naptha/tesseract.js); scanned text never leaves the phone. Open it over https (GitHub Pages) so the browser allows the camera.
